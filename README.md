## 📖 Project Overview

**SuperClub** is a state-of-the-art Sports Management System engineered for modern sports academies and clubs. Built meticulously with React and Supabase, it provides an unparalleled administrative dashboard and user-facing registration flow. Embracing the elegant **"Malachite Obsidian × Liquid Gold"** design language, the interface is enriched with fluid framer-motion animations, custom cursors, and an immersive glassmorphic UI.

## 🌟 Key Features

*   **🌌 Premium UI/UX:** Stunning "Malachite Obsidian × Liquid Gold" aesthetic with dark mode optimization.
*   **✨ Dynamic Interactions:** Custom motion-tracked cursors, interactive particle canvases, and flawless glassmorphism.
*   **📊 Administrative Dashboard:** Comprehensive management of members, teams, events, and club analytics.
*   **🚀 Seamless Onboarding:** Effortless multi-step registration forms for new athletes and staff.
*   **📱 Fully Responsive:** Flawless experience across all devices—desktop, tablet, and mobile.
*   **⚡ Blazing Fast:** Built on Vite + React for lightning-speed performance and instant hot-module-replacement (HMR).
*   **🔒 Secure Backend:** Powered by Supabase for reliable authentication, row-level security (RLS), and database management.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

*   Node.js (v16+ recommended)
*   NPM or Yarn package manager

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/GairikBaidya/SuperClub_Sports-Management-System.git
    cd SuperClub_Sports-Management-System
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Set up environment variables**
    Create a `.env` file in the root directory and add your Supabase credentials:
    ```env
    VITE_SUPABASE_URL=your_supabase_url
    VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
    ```

4.  **Start the development server**
    ```bash
    npm run dev
    ```

5.  **Open the application**
    Visit `http://localhost:5173` in your browser.
